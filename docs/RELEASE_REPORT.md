## 온라인 1:1

`npm run start:online`은 실제 HTTP 방 서버를 실행합니다. 방 참가자는 독립 토큰을 받고, 서버는 카드·기력·방향·목표·중복 제출을 검증합니다. 한쪽 명령은 양쪽이 제출할 때까지 응답에 포함되지 않습니다. 둘 다 제출하면 서버가 기존 `src/game.js`로 판정하고 같은 프레임·최종 상태를 양쪽에 전달합니다. 클라이언트는 주기적으로 상태를 확인하며 새로고침 뒤 세션을 복원합니다. 상대 이탈·연결 끊김과 재대전도 처리합니다. 방은 30분 비활성 시 정리됩니다.

**운영 온라인 모드는 미완료입니다.** 현재 방 저장소는 단일 Node 프로세스 메모리입니다. Vercel Functions의 다중 인스턴스에서 공유되지 않습니다. Vercel 프로젝트 목록은 보였으나 프로젝트 세부·환경 변수·연결 자원 조회가 팀 권한 403으로 거부되어 기존 공유 저장소를 확인하지 못했습니다. CLI도 로그아웃 상태였습니다. 정적 Vercel 배포에서는 ONLINE 버튼을 비활성화하고 사유를 표시합니다. 운영 대전에는 공유 영속 저장소 연결 또는 별도 상시 Node 서버 배포가 필요합니다. 새 유료 자원은 만들지 않았습니다.

## 광고

광고 계정 및 슬롯 설정은 확인되지 않았고 실제 광고는 송출하지 않습니다. 메뉴와 결과 화면에만 슬롯을 준비했습니다. 빌드에서 `ADS_ENABLED=1`, `ADS_CONSENT_READY=1`, 유효한 `AD_CLIENT`, `AD_MENU_SLOT`, `AD_RESULT_SLOT`이 모두 제공되어야 광고 스크립트가 로드됩니다. AdSense 계정 승인과 적용 지역의 동의 관리 설정은 별도 확인이 필요합니다. 전투 화면에는 광고가 없습니다.

## 남은 문제

1. 공유 영속 저장소 또는 운영 Node 서버가 없어 배포 URL에서 온라인 대전은 비활성입니다.
2. 실제 광고 계정·슬롯 및 지역별 동의 관리가 없어 광고 송출은 비활성입니다.
3. WebKit, 실제 스마트폰·태블릿의 메모리 회수와 백그라운드 복귀는 물리 기기로 검증하지 않았습니다.
