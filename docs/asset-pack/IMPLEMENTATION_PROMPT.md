# Codex / Claude Code 원프롬프트 — THREE BEATS 게임화 최종 구현

대상 리포지토리: https://github.com/vividhyeok/3beatsdemo
배포: https://3beatsdemo.vercel.app/

너는 시니어 게임 UI 엔지니어이자 게임플레이 프로그래머다. 현재 저장소 구조 및 규칙/테스트를 먼저 읽고, 첨부된 THREE_BEATS_COMPLETE_ASSET_PACK의 `game_ready/` 에셋을 실제 앱에 적용하라. 신규 에셋 및 코드 변경은 통합 테스트 후 커밋·푸시하라. 기존 게임 규칙을 임의로 바꾸거나 미구현 기능을 구현한 척하지 말라.

## 필수 UI 흐름
1. 앱 시작 시 전체화면 메인 메뉴. `game_ready/ui/backgrounds/main_menu.webp`를 `background-size:cover`로 표시하고, 반응형 비율에 따라 오른쪽에 HTML/CSS START, CHARACTER, OPTIONS 메뉴 버튼을 얹어라. 배경은 버튼이 제거된 버전이다. **이미지 파일에 버튼을 그리거나 카드처럼 고정된 버튼을 사용하지 마라.** 접근성 있는 semantic `<button>`과 hover/focus/disabled를 구현.
2. 캐릭터 선택창: 각 캐릭터의 `characters/{id}/profile.webp`와 전술 프로필 표시. 대전 준비 중 VS 오버레이(`ui/logos/vs.webp`)를 표시. 캐릭터 이미지 합성과 구분이 필요하면 동일 파일 재사용을 먼저 시도.
3. 전투: 화면 대부분을 전장 보드가 차지하게. AI 대전 유지. 상단 양측 HUD에 HP/EN. 하단 손패와 BEAT 1,2,3 단일 예약 슬롯. 예약 슬롯 **클릭 한 번으로 삭제**. 중복된 예약 UI/전투 분석 패널 제거.
4. 적 예약 카드는 `cards/back.webp`를 3장 표시하고 Beat 1/2/3 순서로 각각 실행 직전에 **한 장씩** 뒤집어 공개. 사전 공개 금지. 내 예약 카드는 한 곳에서 편집만.
5. **핵심 재미**: 엔진에서 공격자, 공격 카드, 원점, 타겟 위치, 이동 궤적, 직격/스침/방어 적용 전후 수치, 빗나감 등을 구조화된 이벤트로 받아 (a) 카드 공개 (b) 동시 이동 (c) 공격 범위 하이라이트 (d) 공격 FX (e) 피격 반응·damage popup 순서로 애니메이션. 결과가 인과관계로 보여야 한다. 엔진과 렌더러를 분리. 한 beat 1.5~2초, 2x 및 skip 제공. `vfx/` 아트 CSS transform/opacity 및 Web Animations API 또는 Canvas로 사용. 좌→우 방향 기준으로 FX를 뒤집을 땐 transform scaleX(-1). 오브젝트에 연결된 좌표를 쓸 것.
6. 승패: `ui/backgrounds/result.webp`를 배경으로 패배 캐릭터 lose 이미지 (후면, 낮은 채도/명도) + 승리 캐릭터 win 이미지 (전면, 시선 강조) 레이어링. 선택 플레이어 관점의 win/defeat/draw 타이포 사용. 각 조합별 이미지 새로 생성 금지. 빠른 재대전 기능 구현.
7. UI 글자는 가독성을 최우선으로; 로고 이미지의 스타일을 참조하되 빈번히 바뀌는 숫자·버튼 텍스트는 DOM 폰트 기반. 반응형 16:9 중심, 모바일도 가로 스크롤 없이 동작. 고해상도 이미지 지연로딩/프리로드 및 캐싱 고려.

## 이미지 매핑
`asset_manifest.json`이 실제 경로의 유일한 기준이다. `game_ready/` 폴더를 앱 public 또는 기존 static 에셋 경로로 복사하고 경로를 정합적으로 연결. `ui/buttons/`는 레퍼런스이며 실제 게임에서는 사용하지 않는다. 카드는 6 공용 + 5*4 고유 26장; 3x3 범위는 시전자 중심이고 '앞'은 오른쪽 →. 공격별 대미지 및 이펙트 정확한 값은 src/game.js의 카드 정의/판정이 최우선이다. 프리렌더 수치가 틀리면 CSS 텍스트/동적 범위도 덮어쓰기.

## 인수 테스트
- 메인화면 버튼 100% 클릭 가능, 키보드 탭 탐색 가능.
- 네 캐릭터 모두 선택 가능, 모든 카드 이미지 404 없음.
- 카드 세 장 즉시 예약/원클릭 제거/수정 가능.
- 적 행동은 해당 beat 전에 보이지 않음.
- 이동·직격·스침·MISS·GUARD 모두 전장 시각화되고 HP 결과 엔진과 일치.
- 승패/무승부/KO 정상 처리, 반복 재대전 가능.
- 창 크기 변경, 게임 종료, 다음 라운드 진행 시 stale animation 타이머 없음.
- 테스트 통과, 배포 빌드 성공, 변경점 요약 및 남은 이슈 보고.

**작업 중에는 재현 가능한 실제 오류를 고치고, 시각적 완성도만 올리지 말고 게임플레이 상호작용을 완성해라.**
