# 최종 밸런스 리포트

고정 시드 20261016. 각 방향별 캐릭터 대결 36경기, 총 576경기. 9개 휴리스틱 전략을 섞었다. 승률은 무승부를 0.5승으로 계산했다. 각 셀의 95% 정규 근사 반폭은 약 13~16%p로, 작은 차이를 우열로 판정할 수 없다. 전략 선택과 표본이 제한적이며 탐색 기반 최적 전략의 결과는 아니다.

132개 서로 다른 위치, 16개 캐릭터 조합의 정적 단일 비트 행동 후보를 열거했다. 전체 후보 쌍 수는 369,480개다. 이 수는 엔진 `resolveRound`로 모두 실행한 수가 아니며, 방향, 사거리, 합법적인 목표 칸을 열거한 결과다. 3비트 조합 전체와 전체 경기 상태공간의 완전탐색은 수행하지 않았다.


패치 후에는 `npm run balance:exhaustive`로 4×3의 순서 있는 132개 위치와 16개 캐릭터 조합에서 충분한 EN을 둔 첫 비트 후보 406,344쌍을 검사했다. 두 RAVEN이 동시에 궁극기를 사용하려는 132쌍은 한 개만 존재할 수 있는 함정 소유권 때문에 제외하고, 406,212쌍을 실제 엔진에서 실행했다. 각 결과는 `one-beat-cases.ndjson.gz`에 기록했다. 이 전수검사는 EN 부족, 여러 함정 이력, 선행 비트에 따른 위치와 자원 상태 전체를 포함하지 않는다.

## 변경 내역

- `jack_dash`: 20 / 40 / 20 → 25 / 25 / 15
- `jack_spin`: 25 / 40 / 20 → 30 / 35 / 20
- `raven_trap`: 20 / 40 / 20 → 15 / 45 / 25; 설치 거리 2 → 3
- `raven_push`: 25 / 40 / 20 → 20 / 40 / 20; 전방 3칸 스침 추가
- `raven_ult`: 55 / 60 / 30 → 45 / 65 / 30
- `zeta_slide`: 20 / 40 / 20 → 15 / 40 / 20; 측면 이동 → 전방 대각 이동
- `zeta_long`: 15 / 0 / 0 → 10 / 0 / 0
- `zeta_brake`: 20 / 0 / 0 → 10 / 0 / 0; 방어 15 → 30; 공격 회피 시 EN +15
- `zeta_ult`: 55 / 60 / 30 → 45 / 60 / 30
- `eve_pierce`: 20 / 40 / 20 유지; 1칸 직격 → 스침

그 외 카드는 수치를 유지했다. 4×3 전장의 빠른 교전을 유지하면서 ZETA의 대각 진입과 RAVEN의 설치 사거리를 먼저 시험했다. 일반 이동은 여전히 고유 이동 공격에 비해 기회비용이 크며 후속 패치에서 검증해야 한다.

## 관찰

- JACK → ZETA: 63.9% → 50.0%.
- ZETA → EVE: 20.8% → 45.8%.
- RAVEN → EVE: 26.4% → 31.9%. 여전히 취약하다.

## 남은 위험

- 이 시뮬레이터의 전략은 휴리스틱이며 JACK 돌진 연계의 최적 대응, 3비트 전수탐색, 모든 EN 및 함정 경계 상태를 검증하지 못했다.
- 정적 사거리 수치는 실제 피해나 카드별 승률 기여도를 나타내지 않는다.
- 아트 에셋은 새로 생성했으나 컨택트 시트에서 선화가 단순하게 보여 상용 일러스트 품질 목표에는 추가 작업이 필요하다.
- 다음 패치에서는 RAVEN 대 EVE, 위치별 편향, 회피 환급의 악용 가능성, 일반 이동 사용률을 더 많은 시드와 대응형 정책으로 검증해야 한다.
