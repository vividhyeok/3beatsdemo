# 캐릭터 상성

고정 시드 20261016. 각 방향별 캐릭터 대결 36경기, 총 576경기. 9개 휴리스틱 전략을 섞었다. 승률은 무승부를 0.5승으로 계산했다. 각 셀의 95% 정규 근사 반폭은 약 13~16%p로, 작은 차이를 우열로 판정할 수 없다. 전략 선택과 표본이 제한적이며 탐색 기반 최적 전략의 결과는 아니다.

132개 서로 다른 위치, 16개 캐릭터 조합의 정적 단일 비트 행동 후보를 열거했다. 전체 후보 쌍 수는 369,480개다. 이 수는 엔진 `resolveRound`로 모두 실행한 수가 아니며, 방향, 사거리, 합법적인 목표 칸을 열거한 결과다. 3비트 조합 전체와 전체 경기 상태공간의 완전탐색은 수행하지 않았다.

패치 후에는 `npm run balance:exhaustive`로 4×3의 순서 있는 132개 위치와 16개 캐릭터 조합에서 충분한 EN을 둔 첫 비트 후보 406,344쌍을 검사했다. 두 RAVEN이 동시에 궁극기를 사용하려는 132쌍은 한 개만 존재할 수 있는 함정 소유권 때문에 제외하고, 406,212쌍을 실제 엔진에서 실행했다. 각 결과는 `one-beat-cases.ndjson.gz`에 기록했다. 이 전수검사는 EN 부족, 여러 함정 이력, 선행 비트에 따른 위치와 자원 상태 전체를 포함하지 않는다.
