# 카드별 단일 비트 분석

고정 시드 20261016. 각 방향별 캐릭터 대결 324경기, 총 5,184경기. 9개 휴리스틱 전략의 81개 조합을 각각 4회 평가했다. 승률은 무승부를 0.5승으로 계산했다. 각 셀의 95% 정규 근사 반폭은 대략 5%p이며, 작은 차이를 우열로 판정할 수 없다. 전략 선택이 제한적이며 탐색 기반 최적 전략의 결과는 아니다. 패치 전 기준값은 원본 커밋 `29af40e`의 엔진을 같은 시드와 표본 수로 다시 실행한 결과다.

132개 서로 다른 위치, 16개 캐릭터 조합의 패치 전 정적 단일 비트 행동 후보를 열거했다. 전체 후보 쌍 수는 369,480개다. 이 수는 방향, 사거리, 합법적인 목표 칸을 열거한 결과다. 3비트 결과 조합 전체와 전체 경기 상태공간의 완전탐색은 수행하지 않았다.


패치 후에는 `npm run balance:exhaustive`로 4×3의 순서 있는 132개 위치와 16개 캐릭터 조합에서 충분한 EN을 둔 첫 비트 후보 406,344쌍을 검사했다. 두 RAVEN이 동시에 궁극기를 사용하려는 132쌍은 한 개만 존재할 수 있는 함정 소유권 때문에 제외하고, 406,212쌍을 실제 엔진에서 실행했다. 각 결과는 `one-beat-cases.ndjson.gz`에 기록했다. 이 전수검사는 EN 부족, 여러 함정 이력, 선행 비트에 따른 위치와 자원 상태 전체를 포함하지 않는다.
